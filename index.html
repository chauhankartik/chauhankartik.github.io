The curriculum is split into 4 distinct phases designed to build depth from bare metal and algorithms up to distributed cloud infrastructure:

PHASE 1 (WEEKS 1–4)
Core Foundations

Algorithms, CSES, C Memory Management, Modern C++ STL, Effective Java (90 items), JCiP & FAANG SQL.

PHASE 2 (WEEKS 5–8)
System Design (LLD & HLD)

SOLID principles, GoF patterns, 5 full production LLD systems, and 28 Alex Xu HLD architectures.

PHASE 3 (WEEKS 9–10)
Systems & Databases

OSTEP kernel internals, 5-layer networking, B+ trees & LSM-trees, DDIA, Raft consensus, and Lucene search.

PHASE 4 (WEEKS 11–13)
Infrastructure & Cloud

Kafka, Redis, K8s, Docker, Envoy/NGINX, API security with OAuth2/mTLS, and high-throughput data pipelines.
