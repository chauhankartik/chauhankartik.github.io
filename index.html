A hot take that every senior backend engineer needs to hear: Java 21 Virtual Threads (Project Loom) do NOT replace Netty for high-throughput gateway infrastructure.

Virtual threads simplify blocking synchronous code, but if code touches synchronized or JNI that pins carrier threads, your pool deadlocks. For 1M idle WebSockets, Netty's epoll event-loop wins on memory efficiency.

Why LSM Compactions will quietly destroy your P99 latency if you only tune for write-throughput:

When RocksDB Level 0 reaches capacity, the compaction worker MUST merge-sort L0 into L1. If write ingress outpaces compaction, the engine initiates a write stall. Your p50 is 1.2ms; your p99 spikes to 850ms. Monitor rocksdb.write-stall-micros!

Designing Data-Intensive Applications

by Martin Kleppmann (2017)
⭐ 5.0/5.0 ✅ Completed & Synthesized
Reading Progress100%
"The definitive architecture manual for reliability, scalability, storage engines, and consensus algorithms."
⚡ Key Architectural Learnings:
  • LSM-Trees vs B-Trees: sequential write speed vs deterministic point-read latency.
  • Linearizability (single-op real-time recency) vs Serializability (multi-op transaction isolation).
  • Unreliable NTP clocks: rely on logical clocks or Spanner bounded TrueTime uncertainty.

Database Internals: A Deep Dive

by Alex Petrov (2019)
⭐ 5.0/5.0 📖 Currently Reading (82%)
Reading Progress82%
"From slotted disk pages and ARIES crash recovery up to Raft, Paxos, and distributed consensus."
⚡ Key Architectural Learnings:
  • Slotted Page Layout: Storing record offset pointers in header to prevent block fragmentation.
  • ARIES Recovery: Steal/No-Force buffer management with Redo (repeating history) and Undo.
  • Leveled vs Size-Tiered compaction trade-offs in RocksDB storage engines.
